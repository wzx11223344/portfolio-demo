智能工厂能级提升 · 全流程可观测与指挥平台

一个可运行、可演示、可接入真实数据的智能制造大屏看板与全流程追溯平台。
前端是一块「生产指挥中心」大屏（10 个分屏），后端是 FastAPI + SQLite 实时仿真服务；
并预留了 RTSP 摄像头 与 MES / SCADA / PLC / IoT 真实数据接入层。

🔴 在线演示（GitHub Pages，无需后端，自动回落到实时仿真）：
https://wzx11223344.github.io/smart-factory-dashboard/

另一托管（CloudStudio 静态部署，同样开箱即用）：
https://9b4a9004620c4d2b99481077cf6f4a94.gz5.agentos-app.net

一、它能看什么（10 个分屏）

分屏 内容
总控驾驶舱 各产线实时态势墙：具体产品 ID、健康度、在岗人员、异常流
设备 OEE 可用率 × 性能 × 质量，逐线 OEE 与排名
质量一次合格 FPY 一次合格率、缺陷柏拉图、SPC 控制图
生产进度·订单 工单甘特图（计划 vs 实际）、交期倒计时、延期风险
物流·物料 来料风险分级、AGV 实时位置与载货、成品库存分布
能耗·安环 实时能耗 kW、EHS（废气/噪声/气体）、安全连续运行天数
人员·班组 班组产出、在岗人数、职责
异常 Andon 异常类型/工位/响应时限/闭环率，闭环流转
数字孪生平面图 车间俯视数字孪生：每台设备/工位实时产品·健康·OEE·人员，AGV 载货圈
视频监控 RTSP→WebRTC/HLS 视频网格（未接网关时显示该点位实时传感快照）

设计参照真实企业「生产指挥中心」：顶部 KPI 条（产量·OEE·FPY·订单准时率·计划达成率·能耗·安全天数）、
卡片化、异常红/关注黄/正常绿、下钻与联动、数据底座为 MES+SCADA+PLC+IoT+ERP（秒级）。

二、整体架构

┌──────────────────────────── 浏览器（大屏看板） ────────────────────────────┐
│  大屏看板.html（自包含，离线也能跑）                                        │
│   ├─ 在线模式：定时拉取 /api/bigscreen（真实数据）                          │
│   └─ 离线模式：拉取失败自动回落到内置实时仿真引擎（startSim）               │
└───────────────┬───────────────────────────────┬──────────────────────────┘
                │  HTTP /api/bigscreen           │  RTSP / WebRTC / HLS
                ▼                                ▼
        FastAPI 后端 (server.py)          RTSP 网关 (MediaMTX / Janus)
        ├─ 仿真数据生成 (Sim 线程)  ──────►  摄像头视频流（浏览器 <video>）
        └─ mes_adapter 适配层 ─────────┐
                │                       │
                ▼                       ▼
        SQLite (factory.db)      MES / SCADA / PLC / IoT
        （来料/产品/事件/        （OPC UA / Modbus / MQTT / REST）
         AGV/运单/补贴全链路）
  • 前端混合架构：同一份 大屏看板.html 既能在有后端时显示真实数据，又能在纯静态托管
    （GitHub Pages / CloudStudio）时无缝回落到实时仿真——所以「别人打开就能看到动起来的大屏」。
  • 后端 server.py：FastAPI + SQLite，持续生成来料预测、传感观测、产品事件链、AGV、运单、补贴等真实可运行数据。
  • mes_adapter.py：MES/SCADA 适配层，默认关闭（integration.json 中 enabled:false），
    开启后把真实 OEE / 能耗 / 设备状态注入大屏；拉取失败自动维持仿真，不破坏任何功能。

四、本地运行（带后端，最完整）

# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动后端（默认 http://localhost:8000）
python server.py

# 3. 浏览器打开
#    大屏看板：        http://localhost:8000/大屏看板.html
#    全流程追溯前台：   http://localhost:8000/

Docker 方式：

docker compose up --build
# 打开 http://localhost:8000/大屏看板.html

五、接入真实 RTSP 摄像头

浏览器不能直接播放 RTSP，需经网关转成 WebRTC(WHEP) 或 HLS(.m3u8)：

  1. 按 RTSP_GATEWAY.md 用 MediaMTX / Janus 把 rtsp://... 转成
    https://你的网关/live/cam01.m3u8 或 whep://你的网关/cam01。
  2. 在大屏「视频监控」分屏，每个摄像头卡片下方「配置」框粘贴流地址，回车即接入。
    地址保存在浏览器 localStorage，刷新仍在。
  3. 未配置网关时，卡片显示该点位实时传感快照（产线状态 / 健康度 / 当前产品），不会出现假视频。

六、接入真实 MES / SCADA / PLC / IoT

编辑 integration.json：

{
  "enabled": true,
  "transport": "rest",
  "endpoint": "http://你的MES网关/snapshot",
  "mapping": {
    "oee": "plant.oee",
    "energy_kw": "plant.energy_kw",
    "device_status": "devices"
  }
}
  • transport 支持 rest（零依赖，标准库）/ opcua / modbus / mqtt（需相应 pip 包）。
  • mapping 把网关 JSON 字段映射到 OEE / 能耗 / 设备状态。
  • apply: true 时，真实设备状态/健康度/OEE/能耗会覆盖仿真值；enabled:false 时一切维持仿真。
  • 详细字段与节点配置见 mes_adapter.py 内注释。
